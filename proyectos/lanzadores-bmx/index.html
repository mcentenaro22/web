El proyecto

Del modelo a la documentación de obra.

Torres de largada para BMX conectadas por escaleras y entrepisos de rejilla.

El modelo BIM se utilizó como base para desarrollar la documentación de fabricación y montaje de la estructura.

El desafío

La obra de torres para largada de BMX se dividió en 3 partes: dos torres para dos lanzadores de 6 y 9 metros de altura, conectadas entre sí por un sistema de escaleras y entrepisos de rejilla. Las rampas se terminaron de consolidar con losetas prefabricadas.
