El proyecto

Del modelo a la documentación de obra.

Torre de soporte de maquinaria (ciclones), vinculada con modelos de referencia de obras linderas.

El modelo BIM se utilizó como base para desarrollar la documentación de fabricación y montaje de la estructura.

El desafío

La torre de soporte de ciclones está conectada con otros edificios del predio, por lo que se trabajó con modelos de referencia para lograr la precisión necesaria en la implantación. Como el destino es el soporte de maquinaria, se incorporó al modelo la maqueta de los equipos para garantizar el calce.
